# 애드센스 2차 회귀 수정 (2026-11-28)

- 홈은 기존 React 화면을 유지합니다. 빌드 본문은 #root 안에서 교체되며 PC·모바일 웹 홈 하단에 동일한 15개 제목·요약 카드와 소개·정책 링크를 표시합니다. 본문 전체는 앱 번들에 넣지 않습니다. Capacitor 첫 페인트와 토스 빌드에서는 웹 가이드를 숨깁니다.
- 상품은 빌드된 index.html을 사용하고 홈 본문을 상품 본문으로 완전히 교체합니다. React 상품 상세·리뷰 기능, pc→www 휴대폰 이동, pc canonical과 www alternate를 유지합니다. 광고·상투 문장을 제거하고 삭제/누락은 404, 조회·템플릿 장애는 503으로 처리합니다. 서로 다른 작성자 2명 이상, 각 120자 이상, 합계 500자 이상 리뷰 조건은 그대로 유지합니다.
- PC 이동, SPA catch-all, auth-callback, 관리자·딥링크·토스 진입과 public HTML 별칭을 점검했습니다. 가이드 rewrite는 :slug 하나이며 존재하지 않는 문서는 404입니다. 사이트맵 대표 호스트는 pc이고 www 사이트맵은 pc로 이동합니다. robots.txt도 pc 사이트맵을 가리킵니다.
- 가이드 15편을 합니다체로 다시 쓰고 한계를 각 글 끝에 모았습니다. 본문 숫자 220곳을 사실 파일의 값·산술식으로 연결했습니다. scripts/check-guide-numbers.mjs가 모든 본문 숫자와 계산을 재검증하며 최소 본문은 1,521자입니다. 모바일 비교표는 가로 스크롤과 키보드 접근을 지원합니다. 내부 작업 표현을 공개 문서에서 제거합니다.
- 1차의 신뢰 페이지·가짜 검색량 제거·샘플 레시피 제거·가이드 상세만 웹 광고 허용 정책을 유지합니다.

## 검증

원본 HEAD를 별도 임시 폴더에서 실행해 product-intake-images.test.js(이미지 대체 주소), product-intake.test.js(승인 시 POST 수), send-fcm-consent.test.ts(web 기기 집계)의 동일한 3개 실패를 재현했습니다. 이 영역은 수정하지 않았습니다. 변경본 전체를 검토 사본에서 실행한 결과 282개 중 279개 통과, 위 기존 실패 3개만 남았습니다. 변경 관련 17개 회귀 검사는 모두 통과했습니다. 숫자 220곳 재검증, 임시 폴더 정적 생성(기존 dist/index.html 입력), 상품 54개·404·사이트맵 mock fetch 검증도 통과했습니다.

전체 빌드·브라우저 스크린샷·실기기 검증은 요청 범위에 따라 실행하지 않았습니다. 커밋·푸시·배포·cap sync와 외부 데이터 쓰기도 하지 않았습니다.

재실행: npx vitest run / node scripts/check-guide-numbers.mjs / node scripts/build-editorial.mjs <작업폴더안의 임시 출력폴더> / node scripts/verify-editorial.mjs "" <출력폴더>. 생성기 입력은 빌드된 index.html이며, 외부 스냅샷 경로를 첫 인수로 주면 선별 사실도 그 스냅샷과 대조합니다.
